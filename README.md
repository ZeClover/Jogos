# Jogos do Zé

Site com jogos diversos, feito aos poucos conforme surgem ideias.

## Jogos

- **Caminho do Ninja** (`games/ninja-idle/`) — idle/incremental inspirado no universo Naruto. Treine para ganhar chakra, convoque aliados, compre upgrades, desbloqueie conquistas e ascenda para bônus permanentes.

## Estrutura

Site estático (HTML/CSS/JS puro, sem build). Cada jogo mora em `games/<nome>/` com seu próprio `index.html`, `style.css` e `script.js`, reaproveitando o `style.css` da raiz para o visual compartilhado.

## Hospedagem

- GitHub Pages: publicado a partir da branch `claude/site-diversos-jogos-n9oo7l`.
- Vercel: projeto `jogos-do-ze`, deploy automático a cada push nessa mesma branch.
