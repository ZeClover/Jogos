# Style Bible Visual Oficial v1.0

Direção: Naruto clássico + jogo tático moderno + ilustração anime premium.

Personagens: line-art limpa, cel shading controlado, silhueta reconhecível, idade/roupa/era corretas, leitura boa em retrato pequeno.

Portrait: 1:1, 1024x1024.
Full Body: 2:3, 1024x1536+.
Combat Art: 1536x1024.
Background: 16:9, 1920x1080+.
Item: 1024x1024.
Icon: 512x512.

UI: ninja dossier / pergaminho moderno / RPG tático. Materiais: papel, tecido, madeira, metal, selos, tinta, Chakra. Sem estética de cassino.

Style Base Personagens:
high-quality anime game character illustration, clean confident line art, controlled cel shading, strong readable silhouette, accurate age and canonical-era clothing, dynamic but readable pose, polished tactical RPG character art, consistent proportions, crisp facial features, clear material separation, designed for a premium Naruto-inspired tactical roguelite game, no photorealism, no chibi proportions, no generic modern clothing, no unrelated accessories

Style Base Cenários:
high-quality anime game environment illustration, cinematic but gameplay-readable composition, clean stylized architecture, controlled cel shading, rich environmental storytelling, clear foreground middle ground and background, usable as a tactical RPG background, space preserved for user interface, consistent Naruto ninja-world visual language, no photorealistic rendering, no modern real-world city elements unless canonically appropriate

Style Base Itens:
premium anime game inventory asset, single clearly readable object, clean silhouette, high detail concentrated on identifying features, controlled cel shading, consistent tactical RPG visual language, isolated composition, no unnecessary props, no text, no watermark

Style Base Jutsu:
dynamic anime ninja technique illustration, clear technique silhouette, powerful chakra effects, controlled cel shading, readable action, strong directional energy, canonical-era character appearance, designed as premium tactical RPG ability artwork, no photorealism, no excessive abstract particle clutter

Negative: sem texto, watermark, logos aleatórios, membros extras, duplicações acidentais, roupa/idade/versão errada, armas inventadas, olhos errados, mistura de eras, partículas cobrindo personagem.
