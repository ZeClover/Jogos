# Balanceamento e Gerador Procedural v1.0

Balancear por função, custo, condição, risco, oportunidade, sinergia e disponibilidade.

Nenhum melhor jutsu/personagem universal.

Controle possui orçamento de poder; turnos extras e ações extras são extremamente valiosos.

Diminishing returns em defesa, evasão, redução de custo/dano/cooldown.

RNG cria o problema; jogador cria a solução.

Gerador combina peças validadas, não inventa tudo do zero.

Run: Seed → Era → Condições Globais → Arcos → Regiões → Atos → Mapas → Boss Pools → Eventos → Loot Bias.

Inimigo: Origem → Rank → Função → Natureza → Arma → Jutsu Pool → Passiva → Traço → Nome/Título → Aparência.

Loot: Fonte → Região → Rank → Raridade → Compatibilidade → Estado da Build → Anti-frustração.

Final boss é resultado da run, não puro RNG.

IDs estáveis: CHAR_, JUT_, ITEM_, BOSS_, REG_, EVENT_, ENEMY_, STATUS_, UI_.
