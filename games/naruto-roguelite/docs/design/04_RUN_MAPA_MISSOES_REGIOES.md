# Run, Mapa, Missões e Regiões v1.0

5 atos: Formação (D/C), Ascensão (C/B), Mundo Shinobi (B/A), Crise (A/S), Guerra/Catástrofe (S/SS).

Calendário avança com missões, descanso e viagem. Eventos globais continuam mesmo se ignorados.

Seed determina mapa, eventos, loot, bosses, lojas e modificadores do mundo.

Regiões precisam ter identidade mecânica e de loot, não só visual.

Missões: escolta, captura, assassinato, resgate, infiltração, espionagem, reconhecimento, defesa, sobrevivência, sabotagem, recuperação, investigação, caça, fuga, duelo, proteção, batalha, invasão, interceptação e rastreamento.

Resultados: Sucesso Perfeito / Sucesso / Sucesso Parcial / Falha / Desastre.

Reclassificação é possível: missão C pode virar A por informação falsa. Jogador escolhe continuar, recuar ou buscar reforço.

Gerador: ato → região → rank → objetivo → facção → inimigos → complicação → modificador → recompensa → flags.
