# Interface, UX, Saves, Arquivo Ninja e Estatísticas v1.0

Princípio: informação importante primeiro; profundidade sob demanda.

Grandes listas precisam de busca, filtros, favoritos, ordenação, agrupamento por personagem-base e comparação.

Combate mostra HP, Chakra, Guarda, reação, estados, recursos, ordem de turno, custo, cooldown, alvo, previsão de dano/status, razões dos modificadores e telegraph de boss.

Arquivo Ninja: personagens, jutsus, itens, bosses, inimigos, regiões, eventos, facções, finais, reações. Conteúdo desconhecido pode aparecer como ???.

Crônica: linha temporal da run.

Saves: conta + run, autosave, manual fora de combate, crash recovery, versionamento, migração, export/import desejável.

Acessibilidade: tamanho de texto, contraste, reduzir flashes/tremor, velocidade, remap, modo daltônico. Cor nunca é único indicador.
