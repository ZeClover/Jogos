# Escopo Técnico, Protótipo e Roadmap v1.0

Arquitetura data-driven.
Engine = regras universais
Data = conteúdo
Presentation = UI/arte/VFX

Plataforma inicial: Web/Desktop.

Vertical Slice: 4 personagens (Naruto, Sasuke, Sakura, Shikamaru Genin), País das Ondas, Zabuza, 20–30 jutsus, 10 itens, 4 inimigos, 2 elites, 5 missões.

Protótipo v0.1: 24 personagens, 150+ jutsus, 50 passivas, 115 itens, 20 arquétipos inimigos, 10 elites, 15 bosses, 10 regiões, 40 missões, 50 eventos, 3 atos, 1–2 finais, Ameaça 0–5.

Fases: Fundação → Combate → Jutsus → Reações → Personagens → Inimigos → Boss → Mini-run → Loot → Mapa procedural → Campanha 1 Ato → Progressão → 3 Atos → Visual → Simulações → Testes Humanos.

Pipeline: Conceito → Ficha → Validação → Dados → Asset → Teste → Balanceamento → Release.

Pipeline visual: Ficha → Asset Requirements → Prompt → Imagem → Revisão → Nome → Integração.
