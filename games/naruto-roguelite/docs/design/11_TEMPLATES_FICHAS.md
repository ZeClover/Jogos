# Templates Oficiais de Fichas v1.0

Toda ficha deve ter ID, nome, categoria, versão, raridade, era, status, balance version e asset status.

Templates existentes para:
- Personagem/Versão
- Jutsu
- Boss
- Inimigo/Elite
- Item/Arma/Ferramenta
- Região
- Missão
- Evento
- Invocação
- Transformação
- Passiva
- Reação
- Facção
- Final
- Asset Visual

Toda ficha aprovada termina com ASSETS NECESSÁRIOS e PROMPT VISUAL FUTURO.
